| [ADR-0006](ADR-0006-select-becomes-reroll-not-reset.md) | **Select becomes a reroll, not a reset**: it reseeds each channel's LFSR (new melodic material) and clears the bad-zone fields (`BAD_ZONE_FLAGS`/`DISSONANCE_SCORE`/`STALE_COUNT_*`/`ONSET_WINDOW_COUNT`), and **stops reloading the five steering indices**, so the listener's settings survive the press. `FR-1070` conflated three unrelated things, one of them actively hostile — it discarded every parameter the listener had set. The index reload was a **workaround for a constraint lifted in 2026-07**: it existed because Select was the engine's only bad-zone escape, `IP-0007` made recovery autonomous, and both `Claude.md` and `GDS-04` §5 recorded the supersession in prose without anything re-examining the mechanism it obsoleted. **`GDS-04` §4.1's fixed-point invariant is re-stated, not broken by omission** (second dated amendment): the table constraint and `IP-1100`'s ten-test evidence are untouched, boot still lands on the fixed point, and (a) loses only the clause "and Select-reset" — because Select stops being an event about the indices at all, not because it lands somewhere else. **No `01-vision` change**: a button adds no menu state, so `R217` §3's parked "song regeneration" gap closes inside GDS-01's flat single-running-state model. Boot path unaffected. | 2026-08-21 | Accepted |
